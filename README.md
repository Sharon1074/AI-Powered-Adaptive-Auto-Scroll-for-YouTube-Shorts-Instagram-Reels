# AI-Powered Automatic Scroll

Short description...

## Features

- AI-powered video classification
- Automatic scrolling
- YouTube Shorts support
- Instagram Reels support
- Adaptive user-preference learning

## Tech Stack

- JavaScript
- Chrome Extension Manifest V3
- TensorFlow.js
- MobileNet V2
- HTML5
- CSS3

## How It Works

Video → Frame Capture → MobileNet → Classification
→ Preference Learning → Adaptive Scrolling

## Installation

1. Download/clone the repository
2. Open Chrome Extensions
3. Enable Developer Mode
4. Select "Load unpacked"
5. Choose the project folder
